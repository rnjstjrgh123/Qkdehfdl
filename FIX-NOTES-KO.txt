중앙 경로 수정본

변경 내용
- 이동 경로를 아래쪽 시작점 → 오른쪽 아래 → 중앙 → 왼쪽 아래 → 도착 지점 순서로 정리했습니다.
- 중앙을 통과할 때 이동 수가 남으면 왼쪽 아래 대각선으로 계속 이동합니다.
- 중앙에서 이동 수가 끝나면 중앙에 멈춥니다.
- 서버의 위치 인덱스, 도착 대기(10), 완주(11 이상), 포획 범위와 화면 표시를 동일한 인덱스 기준으로 맞췄습니다.
- 첫 칸에서 빽도는 도착 지점에서 대기하며, 도착 대기 말은 빽도로 이동하지 못합니다.

검증
- node --check server.js 및 apply-fix.js
- npm test
- public/index.html과 루트 index.html 동일성 검사
- 경로 인덱스와 서버의 도착/완주 기준 일치 검사

중요한 한계
이 버전은 기존 숫자형 단일 경로 모델을 유지한 수정입니다. 서로 다른 모서리에서 진입하는 경로 선택을 완전히 분기 처리하는 기능까지 구현한 것은 아닙니다.
