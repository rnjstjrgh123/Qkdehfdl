증강 윷놀이 수정본
==================

수정 사항
1. server.js에서 턴 전환 시 nextTurn()에 방 상태 r을 전달하도록 수정했습니다. 기존에는 nextTurn()을 인자 없이 호출해 이동 직후 서버 예외가 발생할 수 있었습니다. 이 부분이 말 이동 후 응답이 오지 않거나 Render에서 502가 보이는 원인 중 하나였습니다.
2. 말판 시작점(왼쪽 아래)에서 첫 이동이 오른쪽으로 진행되도록 말 위치 계산 방향을 수정했습니다.
3. 서버 응답을 기다리는 요청에 12초 제한을 추가했습니다. 응답이 없을 때 UI가 무한 대기하지 않고 오류 안내를 보여줍니다.
4. 페이지가 브라우저 뒤로/앞으로 캐시에서 복귀할 때 Socket.IO 연결이 끊겨 있으면 다시 연결하도록 했습니다.
5. Socket.IO ping/connect 시간 제한을 명시했습니다.

확인 결과
- node --check server.js 통과
- npm test 통과
- index.html과 public/index.html 동일성 및 증강 선택 흐름 검사 통과

적용 방법
- 이 ZIP을 기존 프로젝트 폴더와 교체하거나 새 폴더에 압축 해제합니다.
- Render에 자동 배포 연결이 되어 있다면, 수정된 파일을 GitHub 저장소에 반영해야 배포됩니다.
- 이 파일은 로컬 수정본이며 GitHub/Render에 자동 업로드되지는 않았습니다.
